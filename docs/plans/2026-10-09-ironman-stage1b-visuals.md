# Iron Man — Stage 1b (Visuals: suit skin reveal, reactor, flames, poses, sounds, HUD, panel) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything the player sees and hears for Stage 1a: Tony's glowing reactor, the Mark 50 suit skin revealed pixel by pixel by the nano wave (helmet closes last), 3D parts on player bones, thruster flames and hover / heavy-landing poses, suit sounds, the energy HUD and the holographic panel. After this plan Stage 1 is shippable.

**Architecture:** Per spec §3.2 the suit body is a **suit skin on the player model** (same for everyone, first-person arm uses it); only 3D parts (helmet mask, flames; later weapons/flaps) are `BakedGeoModel`s attached to player model parts by a new generic `client/anim` player layer — an approved extension of the animation core (`animation-system` §1.5: the user approved "3D parts on bones"; update the skill in the same task). All state comes from the 1a snapshot (`IronManFlags`, `actionElapsed/actionLength`, `resource`). Panel restyle goes through a generic `PanelStyles` registry (default = current drawing).

**Tech Stack:** Forge 47.3.0, Minecraft 1.20.1, Java 17, Mixin 0.8.5, JUnit 5.9.3.

**Spec:** `docs/design/2026-10-09-ironman-design.md` §3, §4.1, §4.2, §7.5, §8.6, §15, §17. Previous plan: `docs/plans/2026-10-09-ironman-stage1-foundation.md` (1a).

Paths as in 1a.

**Interfaces:**
- **Suit skin:** a 64×64 player-format skin of Mark 50. - `PlayerBoneMap`: `armorHead→head`, `armorBody→body`, `armorRightArm→rightArm`, `armorLeftArm→leftArm`, `armorRightLeg→rightLeg`, `armorLeftLeg→leftLeg` (child bones follow parents). Unknown top bone → skipped with one log warning.
- `PlayerGeoLayer` generic: `Provider { List<Part> parts(AbstractClientPlayer, float pt); }`, `Part(BakedGeoModel model, ResourceLocation tex, ResourceLocation glow, float reveal)`. Copies each `ModelPart` pose (after all `setupAnim` TAIL mixins) into the geo bones, renders base + glow. Mark 50 Stage 1 part: helmet `head_mask` — revealed last (spec §4.2 "helmet closes last"), cubes assemble along the bone by `RevealMask.cubeVisible`.
- First person: hand texture = suit skin when worn (via `HeroSkins` hand texture), reveal applied on the arm too.
