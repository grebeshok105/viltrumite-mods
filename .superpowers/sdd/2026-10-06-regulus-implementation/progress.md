## Rulings

- Ruling: carrier rule follows spec §5.1 (minecraft-namespace living, non-player, non-Enemy, no `heartless` tag), NOT the Task-2 dispatch text ("Enemy or non-Regulus player") — the dispatch cites "§8-9" but hearts are spec §5 and the spec is the binding authority; the dispatch text describes the old Codex-Superheroes carrier model the spec explicitly replaced — cost if wrong: hearts bind to hostiles/players, making Regulus unkillable-in-practice and contradicting approved balance.
- Ruling: frozen projectiles stay frozen while Lion is active even if Regulus leaves radius (latch semantics); release only happens on switch-off/cleanup — spec §6.4 ties unfreeze to "любое выключение", not to the aura — cost if wrong: aura-release lets a moving Regulus thaw arrows mid-flight.
- Ruling: `ControlManager.releaseProjectilesFor(caster)` drops projectiles with velocity zero + restored gravity; the ~1.5 repulse impulse hits nearby living opponents, not projectiles — spec §6.4 says "застывшие снаряды падают" (they fall) and the impulse pushes "ближайших противников" — cost if wrong: projectiles launch outward instead of dropping.
- Ruling: impulse/repulse pushes happen on manual and forced off (§6.4 paths); cleanup paths (death/disconnect/hero change) only restore projectiles — §16 cleanup is silent state drop — cost if wrong: disconnect shove is a cosmetic difference only.
- Ruling: negative-effect stripping is per-tick while Lion is active (immunity, not one-shot cleanse on activation) — spec §6.2 lists "Снимаются негативные эффекты" among active-state invariants — cost if wrong: poison/wither applied mid-Lion persists wrongly.
- Ruling: forced-off HP check runs every tick while active, not only inside the overheat branch — spec §6.3 "Если HP ≤ 4" is unconditional; heart backlash (internal) can also push HP to the cutoff — cost if wrong: a low-HP Regulus stays invulnerable past the spec cutoff.
- Ruling: ordinary melee gets the +2%/heart multiplier via `HeroDefinition.meleeDamageFactor` on `Player.attack`'s ATTACK_DAMAGE read; ability/internal/counter damage scale in their own formulas — "once" per spec §5.5 — cost if wrong: melee misses the heart bonus or double-scales.
- Ruling: `ControlKind.IMPULSE` guards the ungated push/launch sites (flight slam, punch launch/block-knock, chop, thunderclap, grabbed launch) — plan §85 names IMPULSE the policy query for knock/push/throw; sites already gated by `hurt()` success don't need it since Lion blocks the hit itself — cost if wrong: a Lion-active Regulus gets shoved by mod knockback despite full external-control immunity.
