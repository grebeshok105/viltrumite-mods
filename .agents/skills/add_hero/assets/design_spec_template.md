# <Имя героя>: дизайн героя

> Дата: YYYY-MM-DD. Источник: <Codex-Superheroes `hero/<id>/` / канон / идея пользователя>.

## 1. Рамки

### 1.1 Фантазия
Одно предложение: кем игрок себя чувствует. Одно предложение: как ему противостоять (контрплей).

### 1.2 Жёсткие ограничения
- Что герой НЕ умеет (явно).
- Что переиспользуется из Viltrumite/общего набора, а что новое.

### 1.3 Обозначения
Тики (20 = 1 с), блоки, урон в половинках сердца.

## 2. Как стать героем
Кнопка выбора расы / предмет / команда. Что происходит при входе (`enter`) и при смене героя.

## 3. Скин
- Поведение (когда меняется, слои, эффекты).
- Ассеты: `textures/entity/hero/<id>.png`, иконки `textures/gui/ability/<id>/*.png`.

## 4. Пассивы
Полёт, урон кулака, падение (`cancelsFallDamage`, `onLanded`), регенерация, иммунитеты, слабости.

## 5. Способности
Для каждой способности отдельный подраздел:

### 5.N <Название>
- **Ввод:** клавиша, нажатие / удержание / переключение.
- **Условия:** когда доступна (`canAct`), что блокирует (контроль, якорь, другой канал).
- **Тайминги:** замах / действие / восстановление в тиках.
- **Эффект:** урон, радиус, дальность, отброс, разрушение блоков.
- **Кулдаун / ресурс.**
- **Отказ и фидбек:** что видит/слышит игрок, если нельзя.
- **Визуал и звук:** поза, VFX (общий набор `HeroFx` / новое), звуки (источник, лицензия CC0).

## 6. Взаимодействия
Способности героя между собой; с другими героями (захват, заморозка, щиты); с мобами и блоками.

## 7. Жизненный цикл
Смерть, выход, смена героя, смена измерения: что сбрасывается (`cleanup`), что сохраняется (`saveHeroState`).
